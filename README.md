# 🎮 Proyecto GameZoneEconomia

## 📖 Descripción
GameZoneEconomia es una aplicación web de comercio electrónico enfocada en videojuegos, consolas y accesorios.  
El proyecto permite a los usuarios **buscar productos**, **agregarlos al carrito**, **realizar compras** y gestionar pedidos de manera sencilla.

Este repositorio contiene el **código fuente completo** y su documentación para facilitar la instalación, uso y comprensión del proyecto.

---

## 🚀 Tecnologías utilizadas
- Next.js – Framework de React para aplicaciones modernas.
- React – Librería para construir interfaces de usuario.
- TypeScript – Tipado estático para mayor robustez.
- Tailwind CSS – Estilos rápidos y personalizables.
- pnpm – Gestor de paquetes eficiente.
- Git / GitHub – Control de versiones y colaboración.

---

## ⚙️ Instalación y ejecución

### 1. Clonar el repositorio
```bash
git clone https://github.com/Gyulianamr/GamezoneEconomia.git
cd GamezoneEconomia
```

### 2. Instalar dependencias
```bash
pnpm install
```

### 3. Ejecutar en modo desarrollo
```bash
pnpm dev
```

La aplicación estará disponible en:  
👉 http://localhost:3000

---

## 📂 Estructura del proyecto
```
app/         → Páginas principales (carrito, checkout, productos, búsqueda, etc.)
components/  → Componentes reutilizables (header, footer, cards, formularios)
public/      → Imágenes y recursos estáticos
styles/      → Estilos globales
context/     → Contexto global (carrito de compras)
hooks/       → Hooks personalizados
data/        → Datos de productos (JSON)
```


## 📌 Objetivos del proyecto
- Simular un e-commerce funcional de videojuegos y accesorios.
- Implementar flujo completo de compra.
- Manejo de estado global con contexto.
